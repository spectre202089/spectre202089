15.09.26 3 пара. Введение в специальность.
		Система ведения электронных конспектов.
	Работа данной системы обеспечивается благодаря набору бесплатных программ, не требующих  высокой производительности 
и длительного обучения. Набор включает:
-Obsidian(Обсидиан) - программа для ведения заметок, построения логических связей между ними и их визуализации.
-GiHub Desktop(ГитХаб десктоп) - программа, реализующая технологию Git в удобном формате, обеспечивая простоту контроля версий. 


			Работа с Obsidian 

	Всё начинается с создания хранилища - папки, в которой будут лежать заметки и файлы настроек хранилища. Далее, согласно шаблону и 
согласованным правилам, будут создаваться заметки, а система автоматически построит логические взаимосвязи. Хранилищ может быть неограниченное 
количество, но для СВЭК необходимо только одно. 

			Работа с GitHub Desktop
	Работу можно начать с создания нового репозитория или добавления существующего. Любые изменения, вносимые в репозиторий будут фиксироваться 
системой. По окончанию раюботы необходимо сделать "снимок" репозитория(комит) - его состояние на текущий момент. Затем изменения загружаются в "облако"
сайт GitHub. 
	На другой машине, где уже есть старая версия этого репозитория, из облака мы получим только изменения в файлах.
