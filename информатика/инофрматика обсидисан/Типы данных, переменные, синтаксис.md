Чтобы проверить тип некоторого значения используется функция **type()** . Внутри скобок помещается значение или переменная. 
```python
print(type(44)) <class 'int'>
x = 'text'
print(type(x)) <class 'str'>

```
Базовые типы данных: 
- int - целые числа
- str(string) - текстовые строки, всегда пишутся в кавычках!!!
- **float** - дробные числа, вещественные числа, записываются через точку.
- **bool** - логические значения True или False.
Литерал - запись фиксированного значения прямо в коде.
Значение - это конкретная информация, которую хранит объект, переменная или выражение.
Объект - экземпляр класса. который может содержать данные и методы для работы с этими данными. 
###Переменные
Переменная - это именованная ссылка на объект в памяти компьютера. Сама переменная не хранит значения, а лишь указывает, где лежит объект, поэтому две переменные могут указывать на один объект.
```python
x = 10

```
Запись состоит из следующих частей:
- идентификатор(имя). Начинается с буквы или знака нижнего подчёркивания далее допускаются буквы, цифры и знак. Python - регистрозависимый, т.е **name** и **NAME** - два разных имени. Использование ключевых слов в названии переменных запрещено. 
- оператор присваивания. Выполняет функцию связывания имени с объектом. Записывается как '='.
- объект, задаваемый литералом или некоторым значением
