Программа для перевода из двоичной в десятичную систему счисления.
Цель: Перевод введённого с клавиатуры числа.(6 знаков).
Ограничения: без использования функции int() для перевода.
```python 
с5 = int(input( ))*2**5
с4 = int(input( ))*2**4
с3 = int(input( ))*2**3
с2 = int(input( ))*2**2
с1 = int(input( ))*2**1
с0 = int(input( ))*2**0
print(c5 + c4 + c3 + c2 + c1 + c0) #int
```
Цель: Перевод введённого с клавиатуры числа, из указанного количества знаков 
Ограничения: без использования функции int() для перевода.
```python
binary_str = input("Введите двоичное число: ") 
if not all(c in '01' for c in binary_str):
	print("Ошибка: введите только 0 и 1")
else:
	decimal_value = 0
	base = 1 
	for char in reversed(binary_str):
		if char == '1':
		decimal_value += base
		base *= 2 
	print("Десятичное значение:", decimal_value)
```
